### 수정 1 — 불릿 정규식이 소수를 말머리로 오인

`BULLET_START`의 `\d+[.)]`가 `0.7`을 `"0."`+`"7"`로 읽어 번호 목록으로 취급했다.
우대금리 표에서 조건과 이자율이 매번 다른 청크로 갈렸다.

- 수정: `\d+[.)](?!\d)`
- 측정: 광고 전체 고유 라인 484개 중 판정이 달라지는 것은 14개이고 **전부 숫자**다
  (`1.0` `0.7` `3.0%p` `94.4%` `2026.6.22.` 등). 진짜 번호 목록은 영향 0.
- 가운뎃점 `·`는 원래 말머리 목록에 없다. 표에서 값의 일부로 쓰여 그대로 둔다.

### 수정 2 — 표 행 복원과 항목 경계

파서가 `layout=table`로 인식하면서 `table` 구조 필드는 **전 영역에서 비어 있다**.
셀 구조를 주지 않아 청커가 표를 산문으로 취급했다.

- 라인 bbox의 세로 겹침으로 표 행을 복원한다(`_same_visual_row`, 겹침 비율 0.5).
  74줄 영역이 51행으로 복원되고 라벨 셀과 값 셀이 한 묶음이 된다.
- 행을 항목 단위로 묶는다. 우선순위는 **파서 라벨 → 좌표** 순이다.

### 수정 3 — 파서 라벨을 청크 경계로 (좌표는 폴백)

파서가 이미 라인마다 템플릿 항목 라벨을 붙여 준다(`예금성상품-적립식:우대금리` 등).
좌표로 같은 경계를 다시 추론하던 것을 라벨로 바꿨다.

- 라벨이 **2종 이상**을 구분해 줄 때만 경계로 쓴다. 1종뿐이면 경계 정보가 없어
  표 전체가 한 덩어리가 된다(`p1_r006`이 26줄 → 1청크로 거칠어져 이 조건을 넣었다).
- 라벨이 없는 행은 직전 항목에 붙인다. 주석이 본문에서 떨어지지 않게 하려는 것이다.

- 외부자료·사전심의·매체 의존 규칙: 접수 메타데이터나 대조자료가 없으면 보류한다.
- 규칙별 근거 검색은 최초 후보를 만든 청크를 버리지 않고, 해당 규칙 판정에 충분한 광고
  문맥을 다시 구성하기 위한 단계다.

### 3.4 판정 계약

- 출력은 적용성 `APPLICABLE|NOT_APPLICABLE|UNDETERMINED`와 판정
  `COMPLIANT|VIOLATION|UNDETERMINED`을 분리한다.
- 운영에서는 확인된 미해당을 화면 본판정에서 제외하되 `excluded_candidates`에 원출력을
  보존한다.
- 짧은 광고는 fine 근거와 coarse 전문을 함께 주며, 불완전 파싱·좁은 창으로 부재를
  확정하지 않는다.
- 반대로 전체 광고 검사가 완료됐고 표시의무의 필수 구성요소가 실제 `MISSING`이면
  `UNDETERMINED`로 물러날 수 없다. 계약 위반으로 재처리한다.
- 모델 confidence는 보정 확률이 아니다. 모든 위반·판단불가는 연구원 검토 대상이다.
- 모델 JSON 구문·계약 오류는 유효 결과를 보존하고 실패한 규칙만 소배치로 재호출한다.

  프로필과 H200 최종 프로필 모두 worker/동적 배치로 병렬 처리할 수 있다.
- 연관 광고·랜딩페이지를 함께 보는 정확한 업무 의미와 관계 종류는 아직 수요사 확인이
  필요하다. 앞 광고 판정을 뒤 광고 정답으로 복사하지 않는다.
- 위반/충족/확인필요 조건과 안내문구가 있는 업무 템플릿을 추가 제공받을 수 있다.
  규제목록 v2와 결합하되 새 법적 규칙을 만드는 자료로 쓰지 않는다.
