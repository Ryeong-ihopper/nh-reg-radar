  위 코드2개와 합쳐10파일1071줄이다. 링크를 현행 실행 계약과 인수인계로 연결하고
  오래된 재개 지침을 제거했다. 현행 실행 계약·프로젝트 규칙·재개 프롬프트를 통합했다.
- Docker/포장은 `infra/operational/runtime-files.json`의125파일 목록을 공유한다.
  requirements2는 설치용으로만 사용하고 최종 이미지에서 제거한다. 서버별 예시2·제안
  schema/예시2, 생성·평가·테스트·CI·DB 이행은 저장소에 남기되 실행 목록에 넣지 않는다.

### 판정·출처 경계와 미완료 작업

- [현행 실행 계약](rule-execution-contract-current.md)을 따른다. 정본271=템플릿239+보완32,
  작업대장305=239+32+추가34, 운영239/보완0을 유지한다. 원문 조건·원자·AND/OR·예외·
  Rule/LLM/사람·코드 종합·정본 gate·인용을 우회하지 않는다.
- 예시 표현/숫자는 완전일치 의무나 광고 증거가 아니다. 연락처 마스킹 기재를 인정하고
  퇴직연금16.5%/1억원을 고정하지 않는다. 선입 원문과 출처를 보존한다. 금융 해석 미확정은
  원문·반례와 함께 사람 검토로 남기고 조건 없는 항목에 조건을 만들지 않는다.
- P1v4/P3v9·실제 줄/문자/bbox/출처와 물리 줄 미인증33원자의 사람 담당을 보존한다.
  HWP 기본은 심의 이미지, HTML은 격리 본문이다. HTML 위에 이미지 bbox를 그리지 않는다.
- 추출 실패·부분 누락·불확실 판독·미검증 복구·좌표 없음·기록 없음을 구별한다.
  좌표 없는 판독 경고도 확인필요로 남긴다. EXTRACTED는 정확도 보장이 아니며 confidence를
  신뢰도 백분율로 표시하지 않는다. 심의필 번호/마스킹 존재·연결 유효기간 범위·전체 적정은
  별개이고 실제 승인/발급/달력 날짜 대조는 미구현이다.
- gold는 예측 해시 동결 후 별도 평가에서만 사용하며 사례 하드코딩을 금지한다.
  현재 자료를 과거 결과에 소급 연결하거나 조회 중 파싱/모델을 재실행하지 않는다.
- 추천 AI 생성/채택 DB 저장·법령 전체 조문/개정 이력·사용자 수정/재추출 작업대는 미연동이다.
