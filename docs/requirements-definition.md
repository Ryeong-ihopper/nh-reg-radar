# 1. 프로젝트 개요

## 1.1 프로젝트 목적

본 프로젝트는 금융상품 광고 시행 전 수행되는 준법감시 및 광고심의 업무를 지원하기 위해, 법령·감독규정·협회 심의기준·내부 매뉴얼·상품설명서·약관·과거 심의사례를 기반으로 광고물의 적정성을 사전 검토하는 AI 에이전트를 구축하는 것을 목적으로 한다.

본 시스템은 상품부서와 준법감시부서가 동일한 기준과 근거를 기반으로 광고 적정성을 검토할 수 있도록 지원하며, 광고물 내 위반 가능 요소를 자동 탐지하고, 누락 문구 및 개선 문구를 제안하며, 관련 근거를 시각적으로 제시하는 PoC 시스템을 구현한다.

---

## 1.2 추진 배경

현재 금융상품 광고심의 업무는 상품부서가 안내장, 메모, 온라인 배너, 모바일 화면, 이벤트 페이지 등 다양한 광고물을 제작한 후, 준법감시부서가 수작업으로 문구, 수치, 필수 고지사항, 강조 표현, 글자 크기, 위치, 시인성, 상품설명서 및 약관과의 정합성을 검토하는 방식으로 운영되고 있다.

이러한 방식은 광고 채널 증가, 디지털 광고물 확대, 상품 구조 복잡화에 따라 다음과 같은 한계를 가진다.

| 구분 | 현행 문제점 |
| --- | --- |
| 업무 효율성 | 광고물별 수작업 검토로 인해 심의 시간이 증가함 |
| 기준 일관성 | 담당자 경험과 해석에 따라 판단 기준이 달라질 수 있음 |
| 근거 추적성 | 검토 결과에 대한 법령·내부기준·심의사례 근거를 체계적으로 추적하기 어려움 |
| 감사 대응 | 사후 감사 시 검토 사유, 판단 근거, 수정 이력 확인에 부담이 있음 |
| 반복 업무 | 필수 문구 누락, 금리 표시 오류, 유의사항 미흡 등 반복 검토 항목이 많음 |
| 광고 유형 다양화 | PDF, 이미지, 모바일 캡처, 배너, SMS, 알림톡 등 비정형 광고물 검토 필요성이 증가함 |

# 2. 적용 범위

## 2.1 PoC 적용 범위

본 프로젝트는 PoC 단계로 수행되며, 우선 예금성 상품 및 일부 이벤트성 금융상품 광고를 대상으로 한다.

| 구분 | 적용 범위 |
| --- | --- |
| 대상 상품군 | 예금, 적금, 입출금 상품, 이벤트성 금융상품 안내 일부 |
| 대상 광고물 | 상품 안내장, 영업점 배포용 메모, 고객 안내문, 모바일·인터넷뱅킹 배너, 이벤트 페이지, 앱 푸시 문구, SMS·알림톡 문구 일부 |
| 입력 파일 | 초기 PoC는 jpg, jpeg, png, pdf, hwp, hwpx. 파일 1개당 최대 50MB |
| 주요 검토 항목 | 필수 문구 누락, 금리·수익률 표시 적정성, 과장·오인 표현, 우대조건 표시, 글자 크기·위치·강조 여부, 상품설명서·약관과의 정합성 일부 |
| 주요 사용자 | 상품부서 담당자, 준법감시 담당자 |

## 2.3 제외 범위

PoC 단계에서는 다음 항목을 제외한다.

| 제외 항목 | 설명 |
| --- | --- |
| 최종 심의 승인 자동화 | AI는 최종 승인자가 아니며, 준법 담당자의 검토를 지원하는 도구로 한정한다. |
| 전 상품군 완전 적용 | 예금성 상품 및 일부 이벤트성 광고를 우선 대상으로 한다. |
| 모든 광고 유형 완전 지원 | PoC 샘플 범위 내 광고 유형을 대상으로 한다. |
| 운영계 시스템 완전 연계 | 내부 표준 플랫폼 적용, 내부환경 포팅, 외부 유사환경 구성은 별도 협의 범위로 한다. |
| 법률 판단의 완전 자동화 | AI 검토 결과는 참고 의견이며, 최종 판단은 담당자가 수행한다. |

# 4. 업무 프로세스 요구사항

## 4.1 현행 업무 흐름

현재 광고심의 업무는 일반적으로 다음 절차로 수행된다.

1. 상품부서 광고안 작성
2. 준법감시부서 검수 요청
3. 준법감시부서 수작업 검토
4. 보완 요청
5. 상품부서 수정
6. 재검토
7. 결재
8. 상품부서 광고 시행

---

## 4.2 개선 업무 흐름

본 시스템 도입 후 목표 업무 흐름은 다음과 같다.

1. 상품부서 광고안 작성
2. 광고물 업로드
3. AI 기반 광고물 인식 및 문구 추출
4. AI 기반 필수 문구, 위험 표현, 표시 기준, 정합성 검토
5. 문제 영역 및 관련 근거 표시
6. 대체 문구 및 보완 문안 추천
7. 상품부서 자가 수정
8. 준법감시부서 검토
9. 심의 의견 초안 및 검토 리포트 확인
10. 최종 심의 및 승인

# 12. 제약사항 및 전제조건

## 12.1 제약사항

| 구분 | 내용 |
| --- | --- |
| PoC 범위 제한 | 예금성 상품 및 일부 금융상품 광고를 중심으로 검증한다. |
| 데이터 한계 | 내부 심의기준, 상품설명서, 약관, 과거 심의사례 제공 범위에 따라 AI 검토 품질이 달라질 수 있다. |
| OCR 한계 | 저해상도 이미지, 흐릿한 캡처, 복잡한 배경의 광고물은 판독 정확도가 낮을 수 있다. |
| 최종 판단 한계 | AI는 검토 지원 도구이며, 최종 심의 판단은 준법감시 담당자가 수행한다. |
| 평가 범위 | 평가 방식, 표본 수, 정답지 구성, 검증 범위는 착수 이후 수요기업과 협의하여 확정한다. |

# 16. 결론

본 프로젝트의 핵심 요구사항은 금융상품 광고심의 업무에서 반복적으로 발생하는 필수 문구 누락, 부적정 표현, 금리·조건 표시 오류, 유의사항 미흡, 상품설명서·약관과의 불일치 등을 AI가 사전에 탐지하고, 관련 법령·내부기준·심의사례에 기반한 근거와 수정 권고를 제공하는 것이다.

PoC 단계에서는 AI가 최종 심의 판단을 대체하는 것이 아니라, 상품부서와 준법감시부서의 광고심의 업무를 지원하는 설명 가능한 검토 도구로 활용되는 것을 목표로 한다.
