## 범위

현재 계획239개 템플릿·32개 보완 규칙의 서비스→접수→검색→요청→출력 검증 연결을 확인했다.
239개 템플릿 원문의 적정/부적정/예외 문장을 사람이 전수 해석한 감사는 아니다. 계획의 의미
정확성 검토는 다음 작업이며, gold를 읽거나 정확도를 주장하지 않는다.

일반 기준은 기존 정본의 unknown 정책·담당 소유자·증거 계약이다. 광고 ID·문장·정답을 실행
규칙으로 추가하지 않았다. 외부자료/사람 확인의 운영 입력 계약은 아직 없으므로 모델 주장만으로
그 담당을 충족 처리하지 않는다. 복잡도12 초과 단일 계획은 기존 배치 함수대로 단독 요청한다.

## 검색 검토

template-only는 선택 템플릿 전수 배분과 광고 근거 검색을 사용한다. 규칙 검색 Recall을 측정한
것이 아니다. 보완 실행은 명시 source policy와 active disposition을 함께 요구한다. 근거 검색의
trigger evidence, P3 영역 근거, line/bbox 연결과 기존 예측 파일은 유지한다. 색인 버전과 벡터
캐시는 실제 문서 내용·모델·출처 해시에 결합하므로 문서 집합 변경 시 새 색인을 만든다.

## 운영 연결과 한계

로컬 http://127.0.0.1:5182 는 인증서를 검증하는 HTTPS 전달을 통해1118 상태를 사용한다.
개발 VM의 신규 SSH 호스트 신뢰 등록이나 도메인 전환은 하지 않았다. 프록시는 loopback에만
바인딩하고 Host/Origin을 검사한다. 로컬 전달 구간만 HTTP이며 서버 구간의 TLS 검증은 유지한다.
로그인·새로고침·원본 이미지·근거 bbox2개를 실제 브라우저에서 확인했다.

새 파서402ab4b의 PDF 디지털 추출은 연결돼 있다. HWP는 내장 이미지만 P1/P3로 넘기므로
이미지 없는 HWP 실패가 남아 있다. 별도 ingest_hwp 함수와 PDF 미리보기 변환을 새 심의 입력
경로에 연결했다고 주장하지 않는다. 원본·실패 기록을 보존했다.
