## 1. 문서 목적

본 문서는 PoC KPI 산출 시 분모에서 제외할 수 있는 샘플 또는 평가 항목의 기준을 정의한다.

평가 제외는 AI 성능을 공정하게 평가하기 위한 장치이며, AI 오답을 제외 처리하기 위한 장치가 아니다.

## 2. 공통 원칙

| 원칙 | 내용 |
| --- | --- |
| 기본값 | 평가 포함 |
| 제외 대상 | 정답 판정 자체가 불가능하거나 PoC 합의 범위를 벗어난 항목 |
| 제외 처리 | KPI 분자와 분모에서 모두 제외 |
| 승인 | 고객사 담당자 또는 PoC 평가 책임자가 확정 |
| 보고 | 제외 건수와 제외 사유별 집계를 KPI 결과와 함께 표시 |

## 3. 제외 사유 코드

| 코드 | 제외 기준 | 예시 |
| --- | --- | --- |
| `OCR_UNREADABLE` | ADR-0053 기준 OCR/Parser confidence `< 0.50`이고 판정에 필요한 광고 문구가 식별되지 않음 | 흐린 이미지, 깨진 글자, 표/이미지 텍스트 누락 |
| `PRODUCT_CONDITION_AMBIGUOUS` | 상품조건이 불명확해 정답 판정이 어려움 | 금리 조건, 수수료, 기간, 우대 조건 자료가 누락 또는 상충 |
| `REFERENCE_NOT_PROVIDED` | 관련 기준자료가 제공되지 않아 근거 판정이 불가능 | 내부 가이드라인, 심의 매뉴얼, 내규 미제공 |
| `SOURCE_FILE_CORRUPTED` | 원본 파일 자체를 정상 처리할 수 없음 | 암호화 PDF, 손상 파일, 페이지 누락 |
| `LABEL_UNCLEAR` | 담당자 판단 또는 정답지가 상충하거나 불명확 | 동일 문구에 서로 다른 기대 상태 등록 |
| `DUPLICATE_SAMPLE` | 동일 샘플 또는 동일 평가 항목이 중복됨 | 같은 광고물 중복 등록 |
| `OUT_OF_SCOPE` | PoC 범위를 벗어난 상품군, 광고유형, 매체 | 합의되지 않은 상품 또는 비대상 광고 채널 |

## 4. 제외하지 않는 기준

| 상황 | 처리 |
| --- | --- |
| AI가 필수 문구 누락을 탐지하지 못함 | 오답 |
| AI가 위험 표현을 과소 탐지함 | 오답 |
| AI가 적정 문구를 위험 표현으로 잘못 탐지함 | 오답 |
| AI가 무관한 근거를 제시함 | 오답 |
| AI가 기준자료를 찾지 못했으나 기준자료는 제공되어 있음 | 오답 또는 `CHECK_REQUIRED` 판정 실패 |
| 문서 형식이 불규칙하지만 사람이 원문을 보고 판단 가능함 | 평가 포함 |
| 내부 가이드라인이 비정형 문서지만 판단 기준으로 사용할 수 있음 | 평가 포함 |
| Annotation 위치 신뢰도만 낮고 판정 대상 문구는 식별 가능함 | 평가 포함. 화면에는 `LOW_CONFIDENCE` 또는 `NOT_LOCATED` 표시 |

## 5. KPI 산식 반영

| 항목 | 처리 |
| --- | --- |
| 제외 확정 항목 | KPI 분자와 분모에서 제외 |
| 제외 후보이나 미확정 | 평가 포함 |
| 제외 항목 수 | `excludedCount`에 반영 |
| 제외 사유별 건수 | 평가 결과의 `exclusionSummary`, `evaluations.exclusion_summary_json`, 또는 `detail_json.exclusion_summary`에 기록 |
| 모든 항목 제외로 분모 0 | `notApplicable=true`, `achieved=false` |

## 6. 변경 관리

평가 제외 기준을 변경할 때는 다음 문서를 함께 확인한다.

- `docs/poc-kpi-formulas.md`
- `docs/api-specification.md`
- `docs/database-specification.md`
- `docs/test-cases.md`
- `docs/adr/ADR-0024-evaluation-exclusion-policy.md`

중대한 제외 기준 변경은 기존 ADR을 직접 덮어쓰지 않고 새 ADR로 대체한다.
