# ADR-0089: IRP 펀드 광고의 ETF·ELB 복수 노출

| 항목 | 내용 |
| --- | --- |
| 상태 | Accepted |
| 날짜 | 2026-09-30 |
| 승인 근거 | 사용자의 “IRP 광고에 펀드랑 etf, elb가 나오는 경우도 있어? 그럼 그것도 추가해야지” |
| 관련 후보·질문 | 후보052·Q82 |
| 관련 ADR | ADR-0087의 상품 조합 원칙을 IRP 펀드 노출에 확장 |
| 관련 문서 | [기능](../functional-specification.md), [화면](../screen-specification.md), [API](../api-specification.md), [테스트](../test-cases.md) |

## 배경

IRP 펀드상품 노출 심의방법은 펀드 의무를 이미 포함하지만 등록 입력은 ETF·ELB가 같은 광고에 함께 등장해도 표현하지 못했다. IRP 금융투자상품 미노출 기준이나 일반 퇴직연금 기준으로 바꾸면 해당 원문의 적용 범위가 달라진다.

## 검토 대안

IRP 펀드 광고에서 추가 운용상품을 받지 않거나, 기존 IRP 펀드 심의방법에 실제 언급된 ETF·ELB만 결합할 수 있다. 사용자 요청에 따라 후자를 채택한다. 원문이 없는 IRP ETF·ELB 단독 유형은 만들지 않는다.

## 결정

IRP 펀드상품 노출을 기본 템플릿으로 유지한다. 함께 언급된 ETF·ELB를 복수 선택해 해당 퇴직연금 운용상품 심의방법을 추가한다. 펀드 기준은 IRP 기본 템플릿에 포함되므로 `투자성상품-펀드`를 또 추가하지 않는다. 기존 `underlying_products[]`와 확정 상태를 사용하고 새 API 필드나 DB 변경은 만들지 않는다.

IRP 금융투자상품 미노출은 ETF·ELB 선택을 허용하지 않는다. 펀드가 없는 IRP ETF·ELB 광고의 독립 심의방법은 현행 원문에 없으므로 펀드 노출 템플릿을 추측해 적용하지 않는다. 다른 미지원 운용상품이 함께 나오거나 노출 여부가 불명확하면 확인필요로 보존한다. 일반 퇴직연금·ISA·IRP 기존 정본 항목과 원문 출처는 수정하지 않는다.

## 검증

IRP 펀드 단독·펀드+ETF·펀드+ELB·세 상품 동시 노출과 금지 조합을 합성 입력으로 검사한다. 등록 화면→routing/intake→정본 전개와 결과 coverage에서 선택한 기준만 유지하며, 임의 템플릿 합집합·누락·중복을 거부한다. 과거 저장 결과와 gold는 재해석하지 않는다.

## 영향 범위

상품 관계 설정, 등록 화면의 운용상품 선택, 현행 정본 전개에 적용한다. IRP 원문 기준과 결과 저장 구조는 바꾸지 않는다.

## 후속 조치

관련 회귀와 필수 문서·거버넌스 검사를 통과시킨 뒤 개인 저장소의 `integration` 브랜치에 반영한다. 펀드 없는 IRP ETF·ELB 광고의 심의방법은 실제 원문 확인 후 별도 결정한다.
