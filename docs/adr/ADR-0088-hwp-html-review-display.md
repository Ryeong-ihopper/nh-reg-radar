## 배경

사용자는 HWP 본문을 HTML로 직접 확인하도록 요청했다. 기존 파서의 이미지 좌표와 HTML 문서 배치를 혼동하지 않으면서 과거 결과도 조회할 수 있어야 한다.

## 검토 대안

이미지 표시만 유지하거나 HTML을 기본 표시하고 좌표 확인용 이미지를 함께 제공할 수 있다. 사용자 요청에 따라 후자를 채택한다.

## 결정

HWP/HWPX는 파서가 생성한 HTML 본문을 직접 표시한다. 저장본이 없는 과거 심의는 같은 원본 체크섬의 파일에서 HTML만 생성하며 OCR·VLM·검색·판정을 재실행하지 않는다. 이미지·PDF의 파싱·표시 경로는 유지한다.

HTML 산출물은 광고·심의·파일 소유권과 원본 체크섬·HTML 해시로 결합한다. HTML을 격리된 iframe에 정적으로 표시하며 원본의 스크립트·이벤트·외부 탐색을 허용하지 않는다. HTML 조회에는 기존 인증·광고 접근 권한을 적용한다.

HTML은 문서 본문 전체를 나타낸다. 현재 DOM에서 유일하게 일치하는 실제 인용 문구만 강조한다. 반복·불일치·영역 수준 인용의 불확실성을 숨기지 않는다. PDF/PNG bbox를 HTML에 겹치지 않으며 좌표 확인은 파서 이미지 모드에서 한다. HTML 화면이 한컴 원본 조판과 동일하다는 주장은 하지 않는다.

파서 내부 HTML→PDF·페이지 이미지 생성은 기존 P1/P3·시각 판독 계약을 위한 과정이다. 사이트 표시를 위해 별도의 PDF 변환을 추가하지 않는다. 이번 변경은 판정 기준과 정답 분리 정책을 변경하지 않는다.

## 검증

원문 소유권·형식·체크섬·HTML 해시·재사용과 HTML 격리, 인용의 유일한 일치/중복을 검사한다. 실제 HWP HTML 표시와 과거 결과 조회를 확인하며 배포 전후 광고·심의·저장 결과 해시를 대조한다.

## 영향 범위

운영 연결부와 결과 화면의 HWP/HWPX 표시 계약에 적용한다. HTML 캐시는 기존 심의 실행 디렉터리에 보관한다.

## 후속 조치

검증 후 웹 이미지를 배포하고 기존 광고·심의·판정 보존 및 실제 브라우저 조회를 확인한다.
