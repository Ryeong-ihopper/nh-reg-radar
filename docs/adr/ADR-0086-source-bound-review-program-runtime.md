# ADR-0086: 출처 결합 판단 절차의 공통 운영 실행

| 항목 | 내용 |

## 배경

조건·의무의 일괄 AND는 택일 방식과 확인전용 항목을 왜곡한다. 별도 예금 실행기의 풍부한 의미가 운영 정본으로 이관되지 않았으며 ISA 승인 개정과 보호문구 적용조건도 교정이 필요하다.

## 결정

기재·의미 충족·금지·조건부·대안 선택·수치 및 날짜 비교·시각 확인·외부 대조·검토 요청을 구별하는 출처 결합 판단 절차를 사용한다. 조건 없는 항목에 내용 발동조건을 만들지 않는다. 선택 템플릿은 내용 조건과 별개인 범위 메타데이터다. 확인전용 항목은 의무 없이 검토 질문을 보존한다.

공통 실행기가 전체 결론을 계산한다. 모델은 원문 사실과 각 검사 결과를 관찰한다. 분기 사실을 규칙 전체의 적용성에서 분리하며 미확정을 거짓으로 바꾸지 않는다. 확인되지 않은 시각·외부자료 입력은 미확정이다. 출처가 부적정을 허용하지 않는 경우 자동 위반을 만들지 않는다.

정본의 출처 SHA와 실행식 SHA를 검증한다. 승인 ISA 3개 수수료 개정은 존재확인으로 반영한다. 입출식 보호문구의 LMS 링크 관련 출처 충돌은 검토 요청으로 남긴다. 달력 한 달과 30일을 구별하며 인용한 원문 날짜로 계산한다. 우대금리 합 비교는 전체 구성·개수·연 단위가 검증되는 지원 표현만 자동 계산한다.

각 조건·검사의 질의로 BGE 및 어휘 근거를 회수하고 원문 관계를 확장한다. 검색 누락은 내용 부재가 아니며 근거 문자 예산 초과는 기록한다. 기존 trigger evidence와 상품 범위를 유지한다.

## 대안

별도 평가 실행기를 운영에 그대로 연결하거나 모든 보완 규칙을 활성화하지 않는다. 공통 표현으로 의미를 이관한다. template-only239 및 보완32 비활성, P1/P3·원문 좌표·평가 분리·기존 결과 보존을 유지한다. 이번 승인은 충돌 원문의 임의 해석이나 239개 의미 정확도 확정을 뜻하지 않는다.

## 영향

요청별 사실·검사 수와 근거 검색 호출이 증가할 수 있다. 기존 저장 결과에는 새 결론을 소급하지 않는다.

## 후속 조치

양성·음성·경계 합성검사와 실제 운영 요청의 계약·최종식·실행 해시를 검증한다. 배포 전후 광고/검토 ID 및 저장 결과 해시를 대조하고 새 회차로 E2E를 확인한다. 배포 실패 시 기존 이미지로 복귀하되 상태와 실패 회차는 삭제하지 않는다.
