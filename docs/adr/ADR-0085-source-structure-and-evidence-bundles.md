# ADR-0085: 원문 구조 보존과 규칙별 근거 묶음 검색

| 항목 | 내용 |
| --- | --- |
| 상태 | Accepted |
| 날짜 | 2026-09-15 |
| 승인 근거 | 검색·판정 개선 제안에 대한 사용자의 “실행 순서 그대로 진행해줘” |
| 관련 문서 | 기능명세서, 테스트케이스, pipeline-design-review-current.md, 후보048·질문 Q78 |
| 관련 ADR | ADR-0065, ADR-0079, ADR-0084 |

## 배경

웹의 파일 병합에서 줄 ID만 바뀌어 원문 관계가 끊기고 문서 최상위 관계가 유실됐다.
검색된 표·각주 구조도 판정 입력에서 빠졌다. 규칙 발견의 하이브리드 검색에 비해
규칙별 광고 근거 검색은 단순하며, 후보 재정렬은 첫 발견 문맥만 사용했다.

## 결정

1. 연결 오류 수정, 구조 보존, 조건·의무별 근거 검색, 용어·복수 문맥 비교,
   의무별 판단과 최종 결론 검증, 독립 평가 순으로 진행한다.
2. 기존 템플릿 주 기준·v2 보완, Elasticsearch 하이브리드 검색, BGE/Gemma,
   적용성 선행 판정, 금지된 답지 누수·사례별 규칙의 경계를 유지한다.
3. 파일별 줄·셀·표·관계 ID와 참조를 함께 변환하고 원본 파일·페이지를 보존한다.
   모델의 표/관계 입력은 제공된 정본 줄에 접지된 구조만 허용한다.
4. 원문 조건·의무·비고를 검색 질의로 분리하되 법적 의무를 임의로 추가하지 않는다.
   기존 근거와 관찰 관계를 우선하고 추가 검색/문맥은 공통 문자 예산을 사용한다.
5. 재정렬은 중복 없는 발견 문맥별 점수를 구해 최고 점수로 결합한다. 후보 삭제나
   자동 미해당 결정에 사용하지 않으며 문맥별 점수와 근거를 감사에 남긴다.
6. 모델은 적용성·개별 의무를 판단하고 검증기는 필수 검사·근거·전체 결론의 일관성을
   검사한다. 불확실성이 다른 독립 위반을 숨기지 않도록 하며 근거 없는 결론을 만들지 않는다.

## 검토 대안

| 대안 | 판단 |
| --- | --- |
| 모델 파인튜닝 우선 | 유실된 원문·관계는 복구하지 못하며 독립 평가 자료가 없어 후순위 |
| 모든 규칙에 광고 전체 구조 전달 | 반복 비용과 무관한 근거 혼입 위험이 있어 규칙별 근거 범위를 유지 |
| 기존 연결 수정 후 근거 묶음 검색 | 출처를 보존하고 회수/판정 실패를 분리해 검증할 수 있어 채택 |

## 영향

- 공개 통합/검색 스키마에 선택적 구조·자산 필드를 추가한다. 기존 자료도 읽을 수 있다.
- 표의 정본 줄 연결이 없는 입력은 구조 활용이 제한된다. 파서가 실제 연결을 제공해야 한다.
- 추가 검색 문맥과 재정렬 쌍이 늘 수 있다. 현재 선택이 최적 속도·정확도라는 결정은 아니다.
- 화면/API/DB의 결과 계약과 기존 운영 결과는 유지한다. 판정 규정 원문은 변경하지 않는다.

## 후속 조치

- 양성·음성·경계 합성검사, 봉인된 개발 입력의 근거 묶음 회귀, 신규 모델 계약 검증을 분리한다.
- 새 광고와 사람이 확정한 정답으로 독립 평가를 수행한다. 개발 자료의 수치를 일반화하지 않는다.
- 복합 의무의 의미 분해는 승인된 원문 구조와 해석 확인 후 진행한다.
- 독립 정확도 확인 후 호출 구성·캐시·파인튜닝을 비교한다. Spark 서비스는 재시작하지 않는다.
