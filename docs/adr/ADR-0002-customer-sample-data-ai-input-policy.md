# ADR-0002: 고객사 샘플 데이터 외부 AI 입력 정책

## 상태

Accepted

## 배경

프로젝트 수행 과정에서 고객사 자료, 광고 원본, 내부 기준자료를 AI 도구에 입력할 가능성이 있다. 금융상품 광고심의 자료는 고객사 업무자료와 내부 기준을 포함할 수 있으므로 외부 AI 입력 가능 범위를 명확히 정해야 한다.

현재 프로젝트에는 고객사가 샘플로 제공한 광고 예시, 규정 및 가이드라인, 계획서 관련 자료가 `docs/` 하위에 정리되어 있다.

## 결정

현재 고객사로부터 샘플로 제공받은 자료는 외부 AI 도구에 입력할 수 있다.

단, 외부 AI 입력 가능 범위는 “제공받은 샘플 데이터”로 제한한다.

추가로 제공되는 고객사 자료, 운영 데이터, 실사용 광고 원본, 개인정보 또는 민감정보가 포함될 수 있는 자료는 고객사 담당자의 승인을 받은 뒤 외부 AI 입력 여부를 결정한다.

## 대안

| 대안 | 판단 |
| --- | --- |
| 모든 고객사 자료 외부 AI 입력 금지 | 보안상 가장 안전하지만 현재 샘플 기반 분석과 문서 정리에 제약이 크다. |
| 제공받은 샘플 데이터는 외부 AI 입력 허용 | 현재 작업 속도와 보안 범위의 균형이 맞다. |
| 모든 고객사 자료를 외부 AI 입력 허용 | 향후 운영 데이터나 민감정보가 섞일 경우 위험이 크다. |

## 결정 근거

- 현재 제공된 자료는 프로젝트 검토와 개발을 위한 샘플 데이터로 간주한다.
- 샘플 데이터는 요구사항, 기능명세, OCR/문서 파서, RAG 검토 품질 확인에 필요하다.
- 신규 자료의 성격은 사전에 알 수 없으므로 고객사 담당자 승인을 예외 절차로 둔다.

## 영향

- Codex, ChatGPT 등 외부 AI 도구는 현재 제공받은 샘플 데이터 범위 내에서 활용할 수 있다.
- 신규 고객사 자료는 기본적으로 외부 AI 입력 가능으로 간주하지 않는다.
- 샘플 데이터와 운영 데이터가 섞이지 않도록 파일 출처와 사용 범위를 문서화해야 한다.
- 개인정보, 계좌정보, 내부 기밀, 미공개 상품 조건 등이 포함된 자료는 샘플 여부와 무관하게 추가 확인이 필요하다.

## 후속 조치

- 신규 자료 수신 시 “샘플 데이터 / 운영 데이터 / 민감정보 포함 가능 자료”를 구분한다.
- 외부 AI 입력 전에 고객사 담당자 승인 여부를 기록한다.
- 샘플 데이터 범위가 변경되면 본 ADR을 갱신하거나 대체 ADR을 작성한다.
