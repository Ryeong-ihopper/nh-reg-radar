## 1. 시작 배경과 기준 정리

- 목표는 예금·대출·투자 광고를 파싱하고, NH 심의 템플릿과 필요한 보강 규제로 검색·판정한 뒤 근거 문구와 bbox를 검사역에게 보여 주는 것이다.
- 초기에는 규제목록 v2를 넓게 전수 실행해 규제목록 비중, 판단불가, 오탐과 모델 비용이 지나치게 커졌다.
- 현재 기준은 **템플릿 중심 + 승인된 추가 규제 32개**다. 예금·대출·투자 범위의 canonical 계획은 템플릿 239개와 보강 규제 32개, 합계 271개다.
- 템플릿에 매핑된 법령·협회 규정은 근거 표시용이며 같은 의무를 별도 판정으로 중복 생성하지 않는다.
- 사례 답지, 특정 광고 문구·숫자·파일명은 운영 규칙에서 분리했다. 사례는 dev/regression 평가에만 사용한다.

## 2. 지금까지 바꾼 핵심 구조

- 규칙을 `적용조건 → 원자 의무 → Rule/LLM/외부자료/사람 → 코드 종합` 순서로 구조화했다. AND·OR·NOT과 최종 판정은 코드가 계산한다.
- Rule 단독 판정은 실제 결정론 어댑터가 있는 경우만 허용한다. 현재 D-163의 명시 산식 검산은 코드가 계산하며, 의미 동등성은 LLM, 색상·크기·배치·대비는 사람 검토로 보낸다.
- 추가 규제는 처분 게이트로 고정했다. `ACTIVE_SUPPLEMENT` 32개만 실행하고 템플릿 지원 9개, 별칭 2개, 보류 8개가 구 v2 경로로 흘러들지 못하게 했다.
- 규칙군별 prompt family를 실제 system prompt에 연결했다. 예시 문구는 검색·해석 힌트일 뿐 완전일치 조건이나 광고 증거가 아니다.
- 파서는 `nh-parser-fin`의 P1 v3/P3 v6으로 전환했다. P1의 OCR/PDF 좌표만 bbox 근거로 쓰고 P3의 `region_id`로 연결하며, VLM 문구에 가짜 line-exact bbox를 만들지 않는다.
- 페이지 상단 위치만으로 내비게이션을 추정하던 로직을 제거했다. 파서가 선언한 header/footer만 PAGE_CHROME으로 보고, 검색 트리거는 필터 뒤에도 보존한다.
- 광고 청킹은 region을 coarse로, 표의 시각 행·비표의 의미 단위를 fine으로 만든다. 문자 보존 검사를 통과해야 하며 짧다는 이유만으로 다른 항목과 합치지 않는다.
- 서버 이전은 fc87의 오래된 벡터 볼륨을 복제하지 않고 spark-1118에 Elasticsearch·BGE-M3·리랭커를 새로 구성하는 방식으로 진행했다. 웹/RAG Python 3.11과 파서 Python 3.13도 분리했다.

## 3. 현재 운영 상태와 다음 확인점

- 실제 서비스는 `template-plus-v2`에서 canonical 계획·이관표·처분표 세 파일을 모두 요구한다. 하나라도 없거나 해시가 다르면 시작하지 않는다.
- 로컬 운영 설정은 구 파서 대신 `nh_parser_fin`과 직접 HTTP 모델 엔드포인트를 사용하도록 바꿨다. 광고주체 인지 가능 여부 같은 임의 등록 필드는 제거했다.
- 규정 검색 인덱스는 256개 규정 원문과 1024차원 BGE 벡터의 내용 해시로 새 이름을 만들며 기존 인덱스를 덮어쓰지 않는다.
- 새 파서 스키마는 청킹 입력 구조와 bbox 연결을 바꾸므로 기존 v1로 만든 26건 감사 결과를 정확도 근거로 재사용할 수 없다. P1 v3/P3 v6 재파싱 후 청크와 광고 임베딩을 다시 만들어야 한다.
- 규정 원문과 검색문은 파서 스키마와 무관하므로 규정 임베딩은 원문·모델·검색문 해시가 같으면 재사용한다. 광고 임베딩은 새 청크에서 항상 다시 계산한다.
- 현재 spark-1118 OCR/VLM/BGE/Gemma 터널이 닫혀 있어 26건 재파싱과 실광고 E2E는 대기 중이다. 연결 복구 후 `파싱 → P1/P3 계약검사 → 청킹 → 광고 임베딩 → 검색 → 판정 → bbox 확인`을 한 흐름으로 실행한다.
- 매 수정마다 전체 회귀를 돌리지 않는다. 변경 영역의 단위·계약 검사를 먼저 돌리고, 실광고 E2E·커밋·배포 전 통합 경계에서 전체 회귀를 한 번 수행한다.
- 기존 심의 결과와 상태 저장소는 보존한다. 새 파싱·검색 산출물은 별도 content-addressed 경로에 만들고 검증 후에만 운영 주소를 전환한다.
