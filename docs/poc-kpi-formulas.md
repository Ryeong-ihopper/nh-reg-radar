## 1. 문서 목적

본 문서는 PoC 성능 평가 KPI를 산출할 때 사용할 분자, 분모, 부분 정답, 제외 처리 기준을 정의한다.

구현, 테스트, PoC 결과보고서는 본 문서와 `docs/adr/ADR-0023-poc-kpi-formulas.md`를 기준으로 한다.

## 2. 공통 산출 원칙

| 원칙 | 내용 |
| --- | --- |
| 평가 단위 | 항목 단위 평가를 기본으로 한다. |
| 점수 산식 | `sum(match_score) / denominator * 100` |
| match score | 정답 `1.0`, 부분 정답 `0.5`, 오답 `0` |
| 제외 처리 | 평가 제외 항목은 분자와 분모에서 모두 제외한다. |
| 분모 0 | `NOT_APPLICABLE`로 표시하고 목표 달성 여부 계산에서 제외한다. |
| 결과 표시 | 점수, 분자, 분모, 제외 건수, 부분 정답 건수, 목표 점수, 달성 여부를 함께 표시한다. |
| 제외 사유 집계 | 제외 사유별 건수를 `exclusionSummary`, `evaluations.exclusion_summary_json`, 또는 `detail_json.exclusion_summary`에 표시한다. |

전체 평균 점수는 보조 지표로만 사용할 수 있다. PoC 목표 달성 여부는 KPI별로 따로 판단한다.

## 3. KPI별 기준

| KPI 코드 | 지표 | 평가 단위 | 분자 | 분모 | 목표 |
| --- | --- | --- | --- | --- | --- |
| `REQUIRED_PHRASE_ACCURACY` | 필수 문구 검토 정확도 | 필수 문구 항목 | 정답지와 일치한 필수 문구 항목의 match score 합계 | 평가 대상 필수 문구 항목 수 | 80% 이상 |
| `MISLEADING_EXPRESSION_ACCURACY` | 위험 표현 검토 정확도 | 위험 표현 항목 | 담당자 판단과 일치하거나 실무상 수용 가능한 위험 표현 항목의 match score 합계 | 평가 대상 위험 표현 항목 수 | 75% 이상 |
| `EVIDENCE_PRECISION` | 근거 매칭 적정성 | AI 제시 근거 | 관련성이 인정된 근거의 match score 합계 | AI가 제시한 평가 대상 근거 수 | 85% 이상 |
| `HUMAN_AGREEMENT_RATE` | 담당자 판단 일치율 | 주요 리스크 항목 | 담당자 판단과 일치하거나 주요 취지가 일치한 리스크 항목의 match score 합계 | 평가 대상 주요 리스크 항목 수 | 75% 이상 |

## 4. 필수 문구 검토 정확도

`REQUIRED_PHRASE_ACCURACY = 필수 문구 match score 합계 / 평가 대상 필수 문구 항목 수 * 100`

| 판정 | match score | 기준 |
| --- | --- | --- |
| 정답 | `1.0` | 필수 문구의 존재/누락/불충분 상태를 정답지와 동일하게 판정 |
| 부분 정답 | `0.5` | 누락 또는 불충분 판단은 맞으나 문구 범위, 위치, 사유가 일부 부정확 |
| 오답 | `0` | 누락을 통과로 보거나, 존재하는 필수 문구를 누락으로 판정 |

필수 문구 유형, 상품군, 광고 유형은 정답지에 명시되어야 한다.

## 5. 위험 표현 검토 정확도

`MISLEADING_EXPRESSION_ACCURACY = 위험 표현 match score 합계 / 평가 대상 위험 표현 항목 수 * 100`

| 판정 | match score | 기준 |
| --- | --- | --- |
| 정답 | `1.0` | 위험 표현 여부, 판정 상태, 위험도가 담당자 판단과 일치 |
| 부분 정답 | `0.5` | 수정 필요 판단은 맞으나 위험도 1단계 차이 또는 사유 일부 누락 |
| 오답 | `0` | 위험 표현을 놓치거나, 적정 표현을 위험 표현으로 잘못 판단 |

담당자가 “실무상 수용 가능”으로 표시한 표현은 정답 또는 부분 정답으로 인정할 수 있으며, 인정 사유를 평가 메모에 남긴다.

## 6. 근거 매칭 적정성

`EVIDENCE_PRECISION = 관련 근거 match score 합계 / AI가 제시한 평가 대상 근거 수 * 100`

| 판정 | match score | 기준 |
| --- | --- | --- |
| 정답 | `1.0` | 기준자료, 조항, 문단 또는 사례가 해당 판단의 근거로 적절 |
| 부분 정답 | `0.5` | 문서는 맞지만 세부 조항이 부정확하거나 근거 관련성이 약함 |
| 오답 | `0` | 해당 판단과 무관한 기준자료 또는 상품자료를 근거로 제시 |

근거를 찾을 수 없는 항목에서 AI가 `기준자료 확인 필요` 또는 `NEEDS_CONFIRMATION`을 반환했고 정답지도 근거 부재를 인정하면, 해당 항목은 오답으로 처리하지 않고 ADR-0024의 평가 제외 기준에 따라 분모 제외 여부를 판단한다.

## 7. 담당자 판단 일치율

`HUMAN_AGREEMENT_RATE = 담당자 판단 match score 합계 / 평가 대상 주요 리스크 항목 수 * 100`

| 판정 | match score | 기준 |
| --- | --- | --- |
| 정답 | `1.0` | 판정 상태와 주요 사유가 담당자 판단과 일치 |
| 부분 정답 | `0.5` | 결론의 주요 취지는 같으나 위험도, 권고 문구, 근거 설명이 일부 다름 |
| 오답 | `0` | 담당자 판단과 반대 결론이거나 핵심 리스크를 누락 |

담당자 판단 일치율은 최종 심의 판단을 AI가 대체한다는 의미가 아니다. PoC에서 AI 검토 결과가 담당자 업무 판단을 얼마나 보조할 수 있는지 확인하기 위한 지표이다.

## 8. 평가 결과 필드

평가 결과는 KPI별로 다음 필드를 포함하는 것이 좋다.

| 필드 | 설명 |
| --- | --- |
| `metricCode` | KPI 코드 |
| `metricName` | KPI 이름 |
| `score` | 산출 점수 |
| `numerator` | match score 합계 |
| `denominator` | 평가 대상 항목 수 또는 근거 수 |
| `excludedCount` | 평가 제외 건수 |
| `partialCount` | 부분 정답 건수 |
| `notApplicable` | 분모 0 여부 |
| `targetScore` | 목표 점수 |
| `achieved` | 목표 달성 여부 |

## 9. 변경 관리

KPI 산식이나 부분 정답 기준을 변경할 때는 다음 문서를 함께 확인한다.

- `docs/functional-specification.md`
- `docs/api-specification.md`
- `docs/database-specification.md`
- `docs/test-cases.md`
- `docs/adr/ADR-0023-poc-kpi-formulas.md`
- `docs/adr/ADR-0024-evaluation-exclusion-policy.md`

중대한 산식 변경은 기존 ADR을 직접 덮어쓰지 않고 새 ADR로 대체한다.
